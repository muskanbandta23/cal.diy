# ZopDay

You can deploy Cal.diy on ZopDay using the button below.

ZopDay can run Cal.diy on ZopCloud, or deploy it into an AWS, GCP or Azure account you already own, so the instance and its database stay on your own billing and inside your own IAM and VPC rules.

## One Click Deployment

[![Deploy on ZopDay](https://zop.dev/deploytozopday-inkhard.svg)](https://zop.dev/zopday/app/deploy?image=calcom/cal.diy:latest&port=3000)
